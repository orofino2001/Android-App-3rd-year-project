# Android-App-3rd-year-project
🏋️ Hypertrophy Tracker App
A comprehensive hypertrophy-focused workout tracking app designed for both beginners and experienced lifters. This mobile application offers an intuitive and user-friendly experience to help users track workouts, visualize progress, and stay motivated, all without the paywalls and clutter of traditional fitness apps.

🚀 Project Vision
The primary goal of this project is to motivate users to improve their physical and mental health by providing a well-rounded and accessible workout tracker. The app supports the creation of workout routines, body measurement tracking, and insightful visualizations like heatmaps and performance charts.

Unlike many existing gym apps, this system focuses solely on useful and necessary features, ensuring a clean, efficient experience without overwhelming the user.

🎯 Features
🔧 Custom Exercise Creation
Create your own exercises tailored to your personal workout needs.

🗓️ Routine Builder
Organize exercises into routines—either user-defined or coach-assisted.

📈 Progress Tracking
Log workouts, monitor bodyweight, muscle measurements, and see performance over time.

🧠 Heatmap Visualization
See which muscle groups are being targeted the most—and which ones are underworked.

🧍 Body Measurements
Track muscle size and body proportions to visualize hypertrophy progress.

📊 Long-Term Data Insights
Compare performance week-over-week or month-over-month using intuitive graphs.

🌐 Community Features (Planned)
Leaderboards, social sharing, and friendly competition to keep users motivated.
